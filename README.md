# Maison Vidy — hotel concept

Concept showcase: a 10-room lakeside boutique hotel in Vidy, Lausanne, with direct booking and a back office.

- Public site: `/`
- Back office: `/office` (demo login on the login page)
- Run order and step specs: `RUN-ORDER.md`, `steps/`

```bash
npm install
npm run dev
```

Demo data lives in the browser (localStorage). "Reset demo data" is in Office → Settings.
